# First Project

First published frontend page: a simple layout built with HTML and CSS. This repo is an early practice project for structure, styling, and static hosting.

**Live pages:** [github.io/First-Project](https://darksnake288-pixel.github.io/First-Project/)

## Stack

- HTML5
- CSS3

## Run locally

```bash
git clone https://github.com/darksnake288-pixel/First-Project.git
cd First-Project
python3 -m http.server 8080
```

Open `http://localhost:8080`, or open `index.html` in a browser.

## Files

| File | Role |
| --- | --- |
| `index.html` | Page markup |
| `style.css` | Layout and visual styles |
